# FolioTeX

> **AI 回答排印与笔记剪辑台** — 粘贴 AI 回答，以学术纸感排版即时渲染全文、公式与表格，点击或划选即可复制到 Obsidian / Typora 等笔记软件。

在线使用：<https://anka-afk.github.io/foliotex/>

## 核心特性

- **学术纸感双栏工作台**：采用暖宣纸浅色与暖炭灰深色双主题，桌面端支持左右分栏拖拽调宽，以及按 `\` 或顶部按钮一键收起输入栏进入专注阅读模式。
- **全文排印渲染**：完整保留原文段落、标题、列表、引用、代码块与 Markdown 表格，行内与行间 LaTeX 公式就地渲染为 KaTeX。
- **点击即复制公式**：点击任意公式即可按目标笔记格式复制（支持 `$...$` / `$$...$$`、`\(...\)` / `\[...\]`、纯公式与原始包装）；按住 `Shift` 点击直接复制无分隔符纯 LaTeX 源码。
- **三线表渲染与一键复制**：Markdown 表格渲染为学术三线表样式，支持对齐、单元格内公式与转义竖线；点击表格任意位置或右上角「复制表格」按钮即可复制整张表格的 Markdown。
- **跨文本、公式与表格智能划选复制**：在全文阅读视图里拖选跨越普通段落、行内公式、行间公式乃至表格的内容后直接按 `Ctrl+C`，自动还原为干净的 Markdown + LaTeX（即使只框选到半个公式也会自动补全完整公式）。
- **复制全文与全篇公式速览**：一键「复制全文」导出按当前格式清洗后的完整 Markdown；按快捷键 `F` 或点击「公式速览」打开全篇公式目录，点击直接复制或「定位 ↵」跳回正文高亮。
- **富文本公式恢复**：粘贴网页富文本时自动从剪贴板 HTML 的 MathML / KaTeX 注解中还原 LaTeX 源码。
- **公式卡片视图**：逐条预览、筛选、搜索公式，默认收起源码保持清爽，点击「编辑」即可原地修改源码并实时重渲染，支持批量复制与导出 `.md`。
- **纯前端离线单文件**：无后端、无外部网络请求，KaTeX 的脚本、样式与字体全部内联进单个 `foliotex.html`，双击即可离线使用；输入内容、格式偏好、分栏宽度与主题自动保存在本地浏览器。

## 快速使用

1. 打开页面，把 AI 回答整段粘贴进左侧输入框（支持直接 `Ctrl+V` 或点击「粘贴」按钮保留富文本注解）。
2. 右侧自动渲染为学术排版稿；可拖动中缝调节宽度，或按 `\` 收起左侧专注阅读。
3. 点击任意公式或表格即可复制，也可跨块划选后 `Ctrl+C`，或切换到「公式卡片」视图批量处理。
4. 在右上角选择目标笔记软件的输出格式，默认是 Markdown（`$` / `$$`）。

## 快捷键

- `Ctrl + Enter`：刷新解析与渲染
- `F`：打开 / 关闭全篇公式速览
- `\`：收起 / 展开左侧输入栏（桌面宽屏）
- `Shift + 点击公式`：跳过包装符，直接复制纯 LaTeX 源码
- `Esc`：关闭公式速览弹窗

## 本地构建

需要 Node.js 18+：

```bash
node build.mjs
node tests/parser.test.cjs
```

构建会生成两个内容相同的离线单文件：

- `foliotex.html`：独立离线版本，双击即可使用。
- `index.html`：GitHub Pages 入口文件。

## 目录结构

```text
src/            页面结构、学术纸感样式、解析器与交互逻辑
tests/          解析器单元测试
vendor/katex/   KaTeX 发行文件（MIT）
build.mjs       离线单文件构建脚本
```

## 已知限制

- 如果剪贴板里既没有 LaTeX 源码，也没有 MathML / KaTeX 注解（例如公式是图片），网页无法还原公式源码。
- 富文本内容使用会话缓存，刷新页面仍可保留；关闭标签页后重新打开时会回退为纯文本渲染。
